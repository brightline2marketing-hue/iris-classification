# Iris Flower Classification

This is a beginner-friendly machine learning project that predicts the species of an Iris flower using its measurements.

## Project goal
Train a simple model to classify iris flowers into one of these three species:
- Setosa
- Versicolor
- Virginica

## Data
This project uses the classic Iris dataset from scikit-learn.

## Setup

```bash
python -m venv .venv
source .venv/bin/activate  # On Windows use .venv\\Scripts\\activate
pip install -r requirements.txt
```

## Run the project

```bash
python iris_model.py
```

## What this project teaches
- Loading a dataset
- Splitting data into train/test sets
- Training a machine learning model
- Evaluating model accuracy
- Making predictions on new data

## Files
- `iris_model.py` — training and prediction script
- `requirements.txt` — Python dependencies
